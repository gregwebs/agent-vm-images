# The reviewed ARG sets of the maintained recipes: one `path NAME...` line per
# recipe, naming every ARG that recipe declares, whole file.
#
# The rule this file carries: an ARG is one more build-time input to a recipe
# whose pins are reviewed as bytes, so a name is a review rather than an edit. A
# recipe that declares a global ARG (one before the first FROM, which is what
# retargets a parent) outside its line is refused, and so is a line that still
# names an ARG its recipe no longer declares - the set is bidirectional so a
# dropped ARG cannot leave a stale permission behind (#235). Whole file and not
# per stage, because the question is whether the recipe has ever named the input;
# which stage reads it is a separate rule (rust-dev's closed instruction set).
#
# Read by both gates, and this file is the only copy of the sets:
#   script/test/example-layers.sh   `reviewed_args`, the four examples/layers
#   script/test/image-sources/tests/image_sources.rs  `reviewed_args`, which
#       include_str!s this file for every maintained recipe
# A recipe added to one reader and not the other is therefore impossible, and a
# new global ARG is one line here instead of an edit in two languages.
